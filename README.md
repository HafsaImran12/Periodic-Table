# 🧪 Periodic Table (HTML & CSS)

## 📌 Description

This project is a **Periodic Table layout** built using only HTML and CSS. It visually represents chemical elements in a structured format similar to the real periodic table.

## 🎯 Features

* 🧩 Structured layout of elements
* 🎨 Color-coded element groups (e.g., metals, non-metals, noble gases)
* 📱 Responsive design
* 🖱️ Hover effects for element interaction
* 🔍 Clean and readable UI

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 Learning Purpose

This project helps in understanding:

* HTML structure and layout
* CSS 
* Styling and positioning
